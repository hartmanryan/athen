# Launch Checklist

Use this checklist to track progress through the full system setup. Present it to the user at the start and update as they complete each item.

## System Overview

| Step | Action | Tool | Automated? |
|------|--------|------|------------|
| 1 | Choose niche + create asset | IDX / Google Drive | Setup only |
| 2 | Run Facebook Lead Form ad | Facebook Ads Manager | Yes (24/7) |
| 3 | Deliver asset via email | Gmail + Zapier | Yes |
| 4 | Send recurring property list | BoldTrail / Gmail | Yes |
| 5 | Send text message to lead | Blutext / Manual | Optional |
| 6a | Add to thanks.io mailing list | thanks.io + Zapier | Yes |
| 6b | Send monthly market update postcard | thanks.io Campaign | Yes (monthly) |

## Checklist Items

### Niche + Asset Setup
- [ ] Identify niche (waterfront, horse property, luxury, etc.)
- [ ] Create or gather lead magnet asset (property list, PDF, video)
- [ ] Host asset online (Google Drive / IDX link / YouTube)

### Facebook Ads
- [ ] Set up Facebook Ads Manager account + Business Page
- [ ] Create Facebook Lead Form ad with niche targeting
- [ ] Test ad with a small budget ($5-$10/day)

### Email Delivery
- [ ] Connect Facebook Lead Ads to Gmail via Zapier
- [ ] Write and schedule initial delivery email
- [ ] Test end-to-end: submit test lead → receive email

### Property Alerts
- [ ] Set up BoldTrail Saved Search with niche criteria
- [ ] Enable auto property alerts for saved search
- [ ] Add test contact and verify alerts are sent

### Text Follow-Up
- [ ] Sign up for Blutext (if automating)
- [ ] Connect Blutext to Facebook Lead Ads
- [ ] Create text campaign with initial + follow-up messages
- [ ] OR: prepare manual text template for personal outreach

### thanks.io Direct Mail
- [ ] Create thanks.io account
- [ ] Design monthly postcard template (6x9 recommended)
- [ ] Create Mailing List for niche
- [ ] Set up monthly Campaign linked to mailing list
- [ ] Create Zapier automation: Facebook Lead → Add to thanks.io Mailing List
- [ ] OR: plan manual process for adding leads + collecting addresses

### Final Validation
- [ ] Test the full funnel end-to-end with a test lead
- [ ] Verify: test lead receives email within minutes
- [ ] Verify: test lead receives text (if using Blutext)
- [ ] Verify: test lead appears on thanks.io mailing list
- [ ] Launch the ad and monitor cost-per-lead for first 7 days

## Common Questions

**How much should I budget for Facebook ads?**
Start with $5-$10/day. Expect leads within 3-7 days. Typical cost is $5-$20/lead for real estate niches. Scale up once you confirm the ad is converting.

**What if I don't have a property list yet?**
Use a free IDX saved search from your broker's website or a public tool like Zillow. The niche and offer matter more than the delivery platform at the start.

**What if leads aren't giving me their mailing address?**
Ask conversationally in follow-up: "I'd love to send you our monthly market update — what address should I use?" Or use thanks.io's email-to-address lookup.

**Do I need Zapier for all of this?**
Not necessarily. Some integrations are native (BoldTrail + thanks.io, for example). Zapier/Make is the most flexible connector. The free Zapier tier may suffice for lower volumes.

**How long before results?**
First leads: 3-7 days after ad launch. Postcard momentum: 3-6 months of consistent monthly mailing before leads respond to physical mail. Stick with it.
